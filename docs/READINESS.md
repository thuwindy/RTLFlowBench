# Experiment and release gates

This is a public research-preview distribution of `golden12-universal-v3-candidate`.
Public file integrity and schema validity are not evidence of evaluator correctness.

## Completed preparation represented here

- Twelve proposed public packets and six-family task definition.
- Explicit scope, acceptance, interface, source and budget files per task.
- Proposed workflow-neutral policy with no double-counted weighted total.
- Public inventory locks, third-party export and submission packaging entry points.
- Public/private distribution boundary; no reference solution or hidden tests bundled.

## Must complete before launching the new scored cohort

1. Bind each policy/profile and exact public packet to its executable evaluator.
2. Revalidate reference, independent alternate, blank, negative and non-equivalent
   mutants as applicable. A no-op QoR baseline is a control, not optimization success.
3. Bind QoR improvement/nonregression predicates to calibration and measurement noise.
4. Lock runner dependencies, container digests, tool versions, seeds, resource budgets,
   timeout classification and the model/provider configuration.
5. Validate all native workflow adapters: startup, tool feedback, stop behavior,
   usage accounting, scope and submission export. Do not spend on broken full runs.
6. Admit the version with accurately identified author/AI/human review roles.
7. Run a small common smoke batch; then launch new isolated repeated runs in batches,
   checking actual usage and infrastructure failures after each batch.

Historical runner hash reconciliation and old calibration receipts remain useful
provenance, but are not a substitute for these candidate-specific gates. No private
receipts or original machine paths are redistributed here.

## Must complete before official v1 / paper claims

- Complete identical-task repeated cohort; record all unsubmitted/blocked/infra slots.
- Offline score eligible submissions, with evidence and missingness accounting.
- Publish six-family matrices, uncertainty/variance, cost and failure analysis.
- Verify cross-host environment reconstruction and redistribution notices.
- Export a public artifact and a separately controlled operator evaluator package.
- Freeze exact version identifiers and disclose AI-only/author-only review if applicable.

Publicizing this preview does not automatically pass any of these gates.
