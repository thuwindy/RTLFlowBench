# G05 repository scaffold

A development materializer has reproduced a minimal projection of the
content-addressed PicoRV32 base. `picorv32.v` is the only editable submission
file and `README.md` is read-only context. This public directory intentionally
contains neither file: the projection is evaluator-managed, has not passed
independent rights review, and is not a frozen public release.

No historical repair, firmware, upstream testbench, evaluator RTL, or hidden
trace belongs in the workflow workspace.
